# Nefes

Sakinleştirici nefes egzersizi uygulaması. React, Tailwind CSS ve Framer Motion ile geliştirilmiştir.

## Çalıştırma

```bash
npm install
npm run dev
```

## Özellikler

- 4-7-8, Kutu Nefesi ve Derin Nefes teknikleri
- Animasyonlu nefes dairesi ve faz geri sayımı
- 3 / 5 / 10 dakikalık süre seçimi
- localStorage ile istatistik, seri ve 7 günlük aktivite
- Web Audio API ile faz geçiş sesi
