Özgün Türkçe haber portalı WordPress teması.

== Description ==
Manşet, son dakika, piyasalar, kategori blokları, yazarlar, video/foto galeri, burç, namaz vakitleri ve daha fazlası.

== Installation ==
1. Temayı wp-content/themes/akishaber klasörüne yükleyin
2. Görünüm > Temalar üzerinden etkinleştirin

== Changelog ==
= 2.1.0 =
* Otomatik oynatmalı, dokunmatik destekli manşet slider ve yandaki manşet listesi.
* Bölüm başlıklarında SVG ikonlar ve yatay kaydırmalı haber rayları.
* Lightbox destekli gerçek foto galeri; haber detayında fotoğraf galerisi.
* 11 adet tema widget'ı: hava durumu, burç, günün sözü, günün ayeti, namaz vakitleri,
  piyasalar, sekmeli haber listesi, foto galeri, sosyal medya, reklam ve haber listesi.
* Öne çıkanlar bloğu yeniden tasarlandı, kategoriler arası tekrar eden haberler engellendi.
* İç içe bağlantı hatası giderildi; kart ve liste görselleri artık doğru hizalanıyor.
* Yönetim panelinden "Haber Görsellerini Yenile" aracı.

= 2.0.0 =
