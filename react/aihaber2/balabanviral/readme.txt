== Description ==

BalabanViral is a magazine-style theme for news and viral content sites.

Features:

* Homepage manşet (dual slider)
* News ticker and light/dark theme switch
* Photo and video gallery archives with slideshow
* Category magazine blocks
* Post feature flags (trending, manset, galleries, filters)
* Reactions and rich sidebar (demo widgets optional)
* Translation-ready text domain: balabanviral

Demo sidebar widgets (weather, FX, markets, etc.) use sample data only and can be disabled under Appearance → Customize → Demo & Sidebar.

Remote Unsplash images are disabled by default. Prefer featured images from the Media Library.

== Installation ==

1. Upload the `balabanviral` folder to `/wp-content/themes/`
2. Activate via Appearance → Themes
3. Optional: Appearance → Demo İçerik to import sample posts
4. Configure Appearance → Customize

== Frequently Asked Questions ==

= Does the theme add content automatically? =

No. Demo content is imported only when an administrator uses Appearance → Demo İçerik.

= Are currency and weather values live? =

No. They are sample demo widgets and can be turned off in the Customizer.
