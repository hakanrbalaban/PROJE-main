# BalabanViral

Viral magazine WordPress theme (GPLv2+).

## Quick start

1. Activate the theme
2. Optional: **Appearance → Demo İçerik**
3. Customize: **Appearance → Customize → Demo & Sidebar**

## Marketplace notes

- No Tailwind CDN (local `utilities.css` + `main.css`)
- Text domain: `balabanviral`
- Demo content is **manual** only
- Remote Unsplash fallbacks are **off** by default (local `placeholder.svg`)
- Demo sidebar widgets can be disabled in Customizer
