# AİORA

AI ile üretilmiş **telifsiz magazin blogu**. Haber / ajans içeriği yok. Teknoloji, yaşam, bilim, kültür ve daha birçok kategoride özgün yazılar; AI kapak görselleri; zengin sidebar widget’ları.

## Çalıştırma

```bash
npm install
npm run dev
```

- Arayüz: http://localhost:5180  
- API: http://localhost:5176  

## Özellikler

- **Ücretsiz AI** — Pollinations public API (metin + görsel). API anahtarı / ödeme yok.
- **AI Yaz** düğmesi ve otomatik periyodik yayın (uzun form makale)
- Haber / finans / hukuk yok — magazin kategorileri
- Telif bildir, DMCA, Hakkımızda, İletişim, Telif politikası
- Sidebar widget’ları (hava, burç, söz, hadis, ayet, namaz, kelime, bilgi)

## AI

```
Metin : https://text.pollinations.ai  (ücretsiz GET)
Görsel: https://image.pollinations.ai (ücretsiz)
```

OpenAI / Anthropic / ücretli key gerekmez. API düşerse yerel uzun şablon kullanılır.

## Telif

Üçüncü taraf haber metni ve yayıncı fotoğrafı kullanılmaz. Kapaklar AI üretilir. İhlal bildiriminde içerik kaldırılabilir.
